## Fixed This Run

### Mobile horizontal overflow on admin/portal pages

**Affected routes (mobile 390px):**
- `/admin/bookings` — 10px overflow (table header button outside scroll wrapper)
- `/admin/messages` — 29px overflow (tab bar items wider than viewport)  
- `/admin/insights` — 87px overflow (jump nav + chart labels)

**Root cause:** `<main>` in `portal-shell.tsx` had no horizontal clip, so `overflow-x-auto` scroll containers bled past viewport width.

**Fix applied:** Added `overflow-x-hidden` to `<main id="main">` in `src/components/portal-shell.tsx`.

## Dev-Mode Console Noise (Not Production Bugs)

**Message:**
```
Error: Route "/admin": Could not validate that a segment in your UI has instant navigation.
This segment was dropped from rendering. Issues that would prevent instant navigation will go undetected.
```

**What it is:** Next.js 16 Turbopack dev-only warning. Fires for every `"use client"` route when the dev server can't instrument the route for its instant-navigation overlay. Does **not** appear in production build (`next build`). Safe to ignore.

**Affected:** All `/admin/*` and `/portal/*` routes in dev mode.
